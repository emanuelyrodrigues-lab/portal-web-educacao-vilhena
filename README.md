# Portal Web de Informações Educacionais para a Comunidade de Vilhena

Projeto acadêmico do Projeto Integrador de Tecnologia da Informação II — UFMS Digital, semestre 2026.2.

## Tecnologias
- HTML5 semântico
- CSS3
- Bootstrap 5.3
- JavaScript do Bootstrap para componentes interativos

## Estrutura
- `index.html`
- `informacoes.html`
- `servicos.html`
- `orientacoes.html`
- `contato.html`
- `css/style.css`

## Execução
Abra `index.html` em um navegador moderno. O Bootstrap é carregado por CDN, portanto é necessária conexão com a internet para carregar os recursos do framework.

## Observação
Antes da publicação final, preencher os canais oficiais da área de contato e substituir o campo de repositório no relatório pelo link real do GitHub.
